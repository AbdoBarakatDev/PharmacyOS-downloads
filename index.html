Use a phone as the barcode scannerاستخدم الهاتف كماسح باركود

Scan this code with an Android phone's camera to download the scanner app. The same code is on the pairing screen in the pharmacy app (This device → Scanner).امسح هذا الكود بكاميرا هاتف أندرويد لتنزيل تطبيق الماسح. نفس الكود موجود في شاشة الربط داخل تطبيق الصيدلية (هذا الجهاز ← الماسح).

  1. Install the app from the code or the link.ثبّت التطبيق من الكود أو الرابط.
  2. Open it and tap “Use this phone as a scanner for a computer”.افتحه واضغط «استخدام هذا الهاتف كماسح لكمبيوتر».
  3. On the computer: This device → Scanner → Pair a phone, then scan its code. Same Wi-Fi for both.على الكمبيوتر: هذا الجهاز ← الماسح ← ربط هاتف، ثم امسح الكود. نفس الواي فاي للجهازين.

Install helpطريقة التثبيت

Installed apps tell you when a newer version is published here.التطبيق المثبّت يخبرك عند نشر إصدار أحدث هنا.

Windowsويندوز

Run the installer. If Windows SmartScreen appears, choose More info → Run anyway. A newer installer updates the app in place; your data stays.

شغّل ملف التثبيت. إذا ظهرت رسالة SmartScreen اختر مزيد من المعلومات ← التشغيل على أي حال. الإصدار الأحدث يحدّث التطبيق في مكانه وتبقى بياناتك.

macOS (Apple silicon)ماك (Apple silicon)

Open the file and drag the app to Applications. The first time, open it from System Settings → Privacy & Security → Open Anyway. Replace the app to update; your data stays.

افتح الملف واسحب التطبيق إلى مجلد التطبيقات. في أول مرة افتحه من إعدادات النظام ← الخصوصية والأمان ← الفتح على أي حال. للتحديث استبدل التطبيق وتبقى بياناتك.

Androidأندرويد

Open the downloaded file and allow installing from this source when asked. A newer file installs over the current app; your data stays.

افتح الملف بعد تنزيله واسمح بالتثبيت من هذا المصدر عند السؤال. الملف الأحدث يُثبَّت فوق التطبيق الحالي وتبقى بياناتك.
